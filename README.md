# fufu ETH/USDT M15 单画线

> FuFu 指标系列 · `fufu_ETH_USDT_M15_单画线.pine`

TradingView **Pine v5** 指标。在 ETH/USDT 图上自动识别水平支撑 / 压力，按 6 类语义分类后
**合并去重成一套线**（同侧、间距内的多条线合成一条），另附「变异支撑带」与扇形趋势线。
**颜色即方向：做多红线、做空绿线。**

设计基准周期 **M15**。

---

## 加载方式

1. TradingView → 打开 ETHUSDT 图表（建议切到 15m）
2. 底部面板 → **Pine 编辑器**
3. 全选删除原有内容 → 粘贴 `fufu_ETH_USDT_M15_单画线.pine` 全部内容
4. 点「保存」→ 点「添加到图表」

> **已加载过旧版本的话**：TradingView 会记住你上次的输入值，新默认色不会自动生效。
> 请在指标设置右下角点一次 **「重置设置」**，或手动把两个颜色改成 支撑=红、压力=绿。

## 配色规则（先看这个）

| 颜色 | 方向 | 位置 | 含义 |
|---|---|---|---|
| 🔴 **红线** | **做多** | 现价**下方** | 支撑 · 逢跌找买点 |
| 🟢 **绿线** | **做空** | 现价**上方** | 压力 · 逢涨找卖点 |

同方向内部：**实线 = 未回踩破**（还没被验证过，实线只表示"还没被碰过"），
**虚线 = 已回踩确认 / 互换位**。金色带是「变异支撑带」，属做多侧。

> 注意：这套红绿是**中国习惯（红涨绿跌）**。如果你的其他指标按国际习惯配色（绿涨红跌），
> 会看起来相反 —— 在「⑦ 颜色」里把两个颜色对调即可，不影响任何逻辑。

## 标签含义与用途（压力侧 / 支撑侧各 3 类）

### 🟢 做空侧（绿线 · 现价上方 · 逢涨找卖点）

| 标签 | 判定 | 线型 | 怎么用 |
|---|---|---|---|
| **压力 · 未破** | 枢轴高点形成后价格**从未回来**过 | 实线 | 从没被回踩，可靠性未知。**别提前埋单**，等第一次触及的反应出来 |
| **压力 · 已回踩** | 被回踩过 ≥1 次，但**守住了** | 虚线 | 被验证过的天花板，**做空的可靠依据**。反抽到此位并出现滞涨形态时进场 |
| **压力 · 互换↓** | 原**支撑被跌破** → 转为压力（角色反转） | 虚线 | 原来的地板被砸穿变成天花板，说明卖方足够强。**反弹至此位附近是二次做空点** |

### 🔴 做多侧（红线 · 现价下方 · 逢跌找买点）

| 标签 | 判定 | 线型 | 怎么用 |
|---|---|---|---|
| **支撑 · 未来买（未破）** | 枢轴低点形成后价格**从未回来**过 | 实线 | 从没被回踩，可靠性未知。等第一次回落的反应再判断 |
| **支撑 · 已回踩** | 被回踩过 ≥1 次，但**守住了** | 虚线 | 被验证过的地板，**做多的可靠依据**。回踩到此位并止跌时进场 |
| **支撑 · 互换↑** | 原**压力被突破** → 转为支撑（角色反转） | 虚线 | 原来的天花板被顶穿变成地板，说明买方足够强。**首次回踩此位常是二次进场点** |

### 一句话总结用途

- **红线密集** = 下方支撑层层叠叠 → 偏多结构，逢跌找多。
- **绿线密集** = 上方压力重重 → 偏空结构，逢涨找空。
- **互换位出现** = 结构刚刚转换，是全套里最值得盯的一类。
- **未回踩破的位** = 没被市场验证过，只观察，不重仓。

> ⚠️ **这是「位置」工具，不是「信号」工具。** 它只回答"价格到哪儿该警惕"，
> 不给出买卖点确认。请配合 K 线形态、成交量与你的止损纪律一起用。

## 核心：合并去重（单画线）

候选池按**优先级顺序**压入，再合并：

```
优先序：未回踩破的支撑 > 未回踩破的压力 > 互换位 > 已回踩位
                ↓
同侧 + 价位差在「同侧合并间距 %」以内  →  合成一条
                ↓
合并时：只要其中任一条是实线档 → 结果为实线
        标签用 · 串联（例：未破 · 互换↑）
        重复的短标签不重复追加（内部带判重）
```

所以「单画线」= 一张图上不出现两条挨在一起的重复线；一个价位只画一次，多余的语义靠标签串联保留。

## 附加结构

### ④ 变异支撑带（做多侧 · 金色）
把「密集低点」聚成一条金色带。带内容差 `0.45%`、最少触点 `3` 个即成形，线宽与颜色可调。
金色是为区别于常规支撑线，**它本身属做多性质**。

### ⑤ 趋势线（扇形展开）
- **下降压力线**：最高摆动高点 → 后续更低高点（🟢 绿 · 做空侧）
- **上升支撑线**：最低摆动低点 → 后续更高低点（🔴 红 · 做多侧）
- 向右延长默认 80 根（15m × 80 = 20 小时）

### ⑥ 手动价位（覆盖 / 追加）
```
价格|标签;价格|标签
例：2615|未回踩破的压力;2460|支撑互换位
```
留空则只用自动识别。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 摆动点 左/右K线数 | 6 / 6 | 越大只认大级别摆动 |
| 识别回看根数 | 700 | 15m × 700 ≈ 7 天 |
| 回踩容差 % | 0.15 | 价格走到距该位多少 % 以内即算「回踩过」 |
| 贴近现价忽略 % | 0.20 | 离现价太近的枢轴不画（噪声） |
| 每类最多几条 | 3 | 先按类别限额，再进入合并去重 |
| 同侧合并间距 % | 0.30 | 调大线更少 |
| 带内容差 % / 最少触点 | 0.45 / 3 | 变异支撑带 |
| 向右延长K线数 | 80 | |
| 线宽 | 1 | |
| 显示配色图例 | 开 | 图表右下角常驻一行「红=做多 / 绿=做空」 |

各组的类别开关（按【做多·红】/【做空·绿】分组标注）与颜色独立可调。

## 图表上的常驻提示

脚本会在**图表右下角**始终绘制两行小字：一行配色图例（可关），一行免责声明（由 `DISC_TXT` 常量控制文案）。
它们跟随最后一根 K 线重算重画，不会堆积残留。


## 两条使用注意

1. **只在最后一根 K 线重算重画**（`barstate.islast`），历史 K 线上不画线。
2. 回踩判定**跳过枢轴自身右侧 `右K线数` 根**，避免同一簇的延续被误判成「回踩过」。
