# fufu ETH/USDT M15 单画线

> FuFu 指标系列 · `fufu_ETH_USDT_M15_单画线.pine`

TradingView **Pine v5** 指标。在 ETH/USDT 图上自动识别水平支撑 / 压力，按 6 类语义分类后
**合并去重成一套线**（同侧、间距内的多条线合成一条），另附「变异支撑带」与扇形趋势线。
**颜色即方向：做多红线、做空绿线。**

另带一条**多空分界线**：先判定当前是多还是空，再按方向**把同侧画线加粗、反向画线改细**，
主次一眼分得开，两侧又都看得到。

设计基准周期 **M15**。

---

## 加载方式

1. TradingView → 打开 ETHUSDT 图表（建议切到 15m）
2. 底部面板 → **Pine 编辑器**
3. 全选删除原有内容 → 粘贴 `fufu_ETH_USDT_M15_单画线.pine` 全部内容
4. 点「保存」→ 点「添加到图表」

> **已加载过旧版本的话**：TradingView 会记住你上次的输入值，新默认色与新增的线宽项不会自动生效。
> 请在指标设置右下角点一次 **「重置设置」**，或手动把两个颜色改成 支撑=红、压力=绿，
> 并把「反向画线处理」确认为 **反向改细线**（旧版的「按趋势过滤」开关已经没了，不复位的话可能还停在隐藏状态）。

## 配色规则（先看这个）

| 颜色 | 方向 | 位置 | 含义 |
|---|---|---|---|
| 🔴 **红线** | **做多** | 现价**下方** | 支撑 · 逢跌找买点 |
| 🟢 **绿线** | **做空** | 现价**上方** | 压力 · 逢涨找卖点 |

同方向内部：**实线 = 未回踩破**（还没被验证过，实线只表示"还没被碰过"），
**虚线 = 已回踩确认 / 互换位**。金色带是「变异支撑带」，属做多侧。

**粗细则表示方向层级**：与当前趋势同向的一侧画粗线，反向的一侧画细线（细线只作参考位）。

> 注意：这套红绿是**中国习惯（红涨绿跌）**。如果你的其他指标按国际习惯配色（绿涨红跌），
> 会看起来相反 —— 在「⑦ 颜色」里把两个颜色对调即可，不影响任何逻辑。

## 标签含义与用途（压力侧 / 支撑侧各 3 类）

### 🟢 做空侧（绿线 · 现价上方 · 逢涨找卖点）

| 标签 | 判定 | 线型 | 怎么用 |
|---|---|---|---|
| **压力 · 未破** | 枢轴高点形成后价格**从未回来**过 | 实线 | 从没被回踩，可靠性未知。**别提前埋单**，等第一次触及的反应出来 |
| **压力 · 已回踩** | 被回踩过 ≥1 次，但**守住了** | 虚线 | 被验证过的天花板，**做空的可靠依据**。反抽到此位并出现滞涨形态时进场 |
| **压力 · 互换↓** | 原**支撑被跌破** → 转为压力（角色反转） | 虚线 | 原来的地板被砸穿变成天花板，说明卖方足够强。**反弹至此位附近是二次做空点** |

### 🔴 做多侧（红线 · 现价下方 · 逢跌找买点）

| 标签 | 判定 | 线型 | 怎么用 |
|---|---|---|---|
| **支撑 · 未来买（未破）** | 枢轴低点形成后价格**从未回来**过 | 实线 | 从没被回踩，可靠性未知。等第一次回落的反应再判断 |
| **支撑 · 已回踩** | 被回踩过 ≥1 次，但**守住了** | 虚线 | 被验证过的地板，**做多的可靠依据**。回踩到此位并止跌时进场 |
| **支撑 · 互换↑** | 原**压力被突破** → 转为支撑（角色反转） | 虚线 | 原来的天花板被顶穿变成地板，说明买方足够强。**首次回踩此位常是二次进场点** |

### 一句话总结用途

- **红线密集** = 下方支撑层层叠叠 → 偏多结构，逢跌找多。
- **绿线密集** = 上方压力重重 → 偏空结构，逢涨找空。
- **互换位出现** = 结构刚刚转换，是全套里最值得盯的一类。
- **未回踩破的位** = 没被市场验证过，只观察，不重仓。

> ⚠️ **这是「位置」工具，不是「信号」工具。** 它只回答"价格到哪儿该警惕"，
> 不给出买卖点确认。请配合 K 线形态、成交量与你的止损纪律一起用。

## 核心：合并去重（单画线）

候选池按**优先级顺序**压入，再合并：

```
优先序：未回踩破的支撑 > 未回踩破的压力 > 互换位 > 已回踩位
                ↓
同侧 + 价位差在「同侧合并间距 %」以内  →  合成一条
                ↓
合并时：只要其中任一条是实线档 → 结果为实线
        标签用 · 串联（例：未破 · 互换↑）
        重复的短标签不重复追加（内部带判重）
```

所以「单画线」= 一张图上不出现两条挨在一起的重复线；一个价位只画一次，多余的语义靠标签串联保留。

## 附加结构

### ④ 变异支撑带（做多侧 · 金色）
把「密集低点」聚成一条金色带。带内容差 `0.45%`、最少触点 `3` 个即成形，线宽与颜色可调。
金色是为区别于常规支撑线，**它本身属做多性质**。

### ⑤ 趋势线（扇形展开）
- **下降压力线**：最高摆动高点 → 后续更低高点（🟢 绿 · 做空侧）
- **上升支撑线**：最低摆动低点 → 后续更高低点（🔴 红 · 做多侧）
- 向右延长默认 80 根（15m × 80 = 20 小时）

### ⑥ 手动价位（覆盖 / 追加）
```
价格|标签;价格|标签
例：2615|未回踩破的压力;2460|支撑互换位
```
留空则只用自动识别。

## 多空分界与趋势分层（本版新增）

图上现在有两条信息主线：**水平线回答「到哪儿该警惕」，分界线回答「现在是哪一边」。**

### 分界线怎么算

| 当前方向 | 分界线取值 | 换边条件 |
|---|---|---|
| 📈 **做多** | 最近一个**已证实的摆动低点** | 收盘价**跌破**分界线 −0.15% → 转做空 |
| 📉 **做空** | 最近一个**已证实的摆动高点** | 收盘价**突破**分界线 +0.15% → 转做多 |

分界线因此会**顺着结构走**：多头里被不断抬高的低点顶上去（相当于移动止损），
空头里被不断降低的高点压下来。它同时也是**结构止损位**。

标签直接写清换边价位：

```
多空分界 · 做多 ｜ 收盘跌破 76143.81 转空
```

> 判定方向时只看**本方向那一侧的枢轴**：做多时只问「有没有跌破低点」，不去看高点。
> 否则价格在区间里来回震荡时，两侧条件会轮流成立，方向反复翻转。

### 趋势分层（粗线 / 细线）

分界线判定出方向之后，两侧画线**全都保留**，只改粗细：

| 当前趋势 | 粗线（顺趋势，主看） | 细线（逆趋势，仅参考） |
|---|---|---|
| 📈 **做多** | 🔴 做多侧：支撑线 + 变异支撑带 + 上升支撑线 | 🟢 做空侧：压力线 + 下降压力线 |
| 📉 **做空** | 🟢 做空侧：压力线 + 下降压力线 | 🔴 做多侧：支撑线 + 变异支撑带 + 上升支撑线 |

线宽在「⑦ 颜色」里可调：**同向线宽**默认 `2`，**反向线宽**默认 `1`。
细线的标签也自动降为小号字；**变异支撑带**是面不是线，光靠边框粗细不好分辨，
所以反向时除了边框变细，还会额外叠一层透明度淡化。

三种模式（「⑧ 反向画线处理」）：

| 模式 | 效果 |
|---|---|
| **反向改细线**（默认） | 两侧都画，同向粗、反向细 |
| **反向完全隐藏** | 只留同向一侧，画面最干净 |
| **不区分粗细** | 两侧同宽，等于回到「不分层」 |

图表左上角会常驻一行状态：

```
📈 趋势：做多　【做多 · 红】粗线为主 ｜ 【做空 · 绿】细线为参考　｜　分界 83502.30（跌破转空）
```

> 💡 为什么默认不是「隐藏」：做多趋势下把上方全藏掉，你就看不到上方的目标位和压力在哪。
> 改细线既保住了主次，又不丢信息。真要图面极简，切到「反向完全隐藏」就行。

### 参数为什么是 14 / 0.15%

分界用的枢轴粒度**和画线用的不是同一套**：画线找的是具体价位（粒度 6），分界判的是大结构（粒度 14）。

实测（900 根 15m ≈ 9.4 天）：

| 分界枢轴 | 穿越 % | 方向翻转次数 | 持有中位 |
|---|---|---|---|
| 6 | 0.15 | 14 次 | 48 根 |
| **14** | **0.15** | **6 次** | **124 根** |
| 20 | 0.80 | 3 次 | 285 根 |

粒度 6 时价格稍有回踩就换边，图上会不停翻；换成 14 之后降到 6 次、平均持有 31 小时。

> 这组参数是在 BTC 15m 上扫出来的。ETH 波动结构不同，如果你觉得方向翻得太勤就往上调
> 「分界 摆动点」，觉得太迟钝就往下调。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 摆动点 左/右K线数 | 6 / 6 | 越大只认大级别摆动 |
| 识别回看根数 | 700 | 15m × 700 ≈ 7 天 |
| 回踩容差 % | 0.15 | 价格走到距该位多少 % 以内即算「回踩过」 |
| 贴近现价忽略 % | 0.20 | 离现价太近的枢轴不画（噪声） |
| 每类最多几条 | 3 | 先按类别限额，再进入合并去重 |
| 同侧合并间距 % | 0.30 | 调大线更少 |
| 带内容差 % / 最少触点 | 0.45 / 3 | 变异支撑带 |
| 向右延长K线数 | 80 | |
| 同向线宽（粗） | 2 | 与当前趋势同向那一侧的线宽 |
| 反向线宽（细） | 1 | 反向那一侧的线宽。设成与上面相同 = 不区分粗细 |
| 显示配色图例 | 开 | 图表右下角常驻一行「红=做多 / 绿=做空 / 粗=顺趋势 / 细=逆趋势」 |

各组的类别开关（按【做多·红】/【做空·绿】分组标注）与颜色独立可调。

### ⑧ 多空分界与趋势分层

| 参数 | 默认 | 说明 |
|---|---|---|
| 显示多空分界线 | 开 | 关掉只是不画那条加粗实线，趋势分层仍按内部方向生效 |
| 反向画线处理 | 反向改细线 | `反向改细线` = 两侧都画、反向侧细；`反向完全隐藏` = 只留同向一侧；`不区分粗细` = 两侧同宽 |
| 显示趋势状态标签 | 开 | 图表左上角常驻「📈 趋势：做多 ｜ 哪一侧是粗线」 |
| 分界 摆动点左/右K线数 | **14** | 分界专用枢轴粒度。画线用的是 6，两者互相独立 |
| 分界穿越确认 % | **0.15** | 收盘价须超出分界线这个幅度才认定翻转，滤掉假突破 |
| 分界线宽度 | 2 | 画在最上层，比普通线粗 |
| 做多 / 做空 分界线 | 🔴 / 🟢 | 跟随「⑦ 颜色」的方向语义 |

## 五条使用注意

1. **只在最后一根 K 线重算重画**（`barstate.islast`），历史 K 线上不画线。
2. 回踩判定**跳过枢轴自身右侧 `右K线数` 根**，避免同一簇的延续被误判成「回踩过」。
3. **多空分界的方向是逐根 K 线累积出来的**——状态机写在全局作用域，只有绘制在 `barstate.islast` 里。
   这条很关键：如果把状态机也塞进 `barstate.islast`，它只在末根算一次，方向会永远停在「尚未判定」。
4. 想换回「只显示同向一侧」，把「⑧ 反向画线处理」改成 **反向完全隐藏** 即可，不用删脚本重加。
5. 粗细差异靠 TradingView 的 `line.width`。**最细只能到 1**，所以想让对比更明显，是把「同向线宽」往上调（3 或 4），而不是把细线调到 0。
